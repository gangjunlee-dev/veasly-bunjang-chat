[번개장터 채팅 모니터 사용법]

접속: https://bunjang-monitor.pages.dev

번개장터 채팅을 한 화면에서 보고, 바로 답장할 수 있는 대시보드입니다.

[사용법]
1. 슬랙/텔레그램에서 새 메시지 알림 확인
2. 위 URL 접속
3. "답장 필요" 초록 뱃지 채팅 클릭
4. 대화 내용 확인 후 하단 입력창에 답장 → Enter
   (번개장터 앱 안 열어도 됩니다)

[알아두면 좋은 것]
- 기본 화면에 답장이 필요한 채팅만 표시됩니다
- 검색창에서 판매자 이름/채팅 내용 검색 가능
- 결제완료, 배송완료 같은 시스템 메시지는 자동으로 숨겨져 있습니다
- 내(veasly)가 보낸 답장은 알림이 안 갑니다
- 모바일에서도 사용 가능합니다

[문제가 있으면]
- "답장 OFF"로 표시되면 → 관리자에게 토큰 재등록 요청
- 채팅이 안 보이면 → 좌측 상단 "폴링" 버튼 클릭

* 팀 내부 전용 URL입니다. 외부 공유 금지!
